# Hell Run GOAP

Data-authored Goal-Oriented Action Planning (GOAP) framework for Unreal Engine 5 with runtime planning, debugging, simulation, and graph-editor tooling.

**Version:** 1.0.0  
**Category:** AI  
**Status:** Beta  
**Modules:** `HellRunGOAP` (Runtime), `HellRunGOAPEditor` (Editor)

## Installation

From your Unreal project's `Plugins` directory:

```bash
git clone https://github.com/Andressalazar005/HellRunGOAP.git HellRunGOAP
```

Expected layout:

```text
YourProject/
  Plugins/
    HellRunGOAP/
      HellRunGOAP.uplugin
      Source/
      Content/
```

Then:

1. Close Unreal Editor.
2. Delete the plugin's `Binaries/` and `Intermediate/` folders if they were generated by a different Unreal Engine version.
3. Regenerate project files if required by your C++ workflow.
4. Build the project's **Development Editor** target, or launch the project and allow Unreal to rebuild the source plugin.
5. Open **Edit > Plugins** and enable **Hell Run GOAP** if it is not already enabled.
6. Restart the editor if prompted.

## Requirements

- Unreal Engine 5 project with a working C++ build toolchain.
- No additional plugin dependency is declared by `HellRunGOAP.uplugin`.

## What the plugin provides

- Runtime GOAP planning.
- Data-authored planning content.
- Editor graph tooling.
- Debugger and simulator support for inspecting planner behavior.
- Plugin content support for authored assets.

## Verify the installation

- Confirm `HellRunGOAP` and `HellRunGOAPEditor` both compile.
- Confirm the plugin appears under the AI category in **Edit > Plugins**.
- Open the project and check the Output Log for module or asset-load errors before migrating planner data.
- When integrating existing AI, validate planner state and actions in a small test scenario before enabling the system across many agents.

## Used by

`HellRunTacticalLab` declares `HellRunGOAP` as a required plugin dependency. Install this repository before compiling Tactical AI Lab.

## Updating

```bash
cd YourProject/Plugins/HellRunGOAP
git pull
```

When changing Unreal Engine versions, delete `Binaries/` and `Intermediate/` before rebuilding.
